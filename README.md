# 永恒纪事 · Astro 静态游戏站

安装 Node.js 22.12+ 后，在本目录执行 `npm install`、`npm run dev`。生产构建执行 `npm run build`，将 dist 部署至静态托管服务即可。

内容集中在 `src/data/articles.js`：新增文章对象即可自动生成文章页并加入搜索与分类。图片存放 public。页面样式在 src/styles/global.css。

已包含：首页、游戏分类、AION2 专区、6 篇文章、浏览器本地搜索与分类、关于、联系方式、隐私政策。无登录、评论和数据库。

参考：日本 AION2 官网提供资讯和图片；影之刃零官网提供深色电影感的视觉方向；永恒蜂窝作为游戏门户的信息架构参考，其页面无法通过文本抓取完整读取。没有复制其代码和布局。

正式运营前请补充 src/pages/[info].astro 中的真实联系方式，核对内容版本并确认游戏图片使用许可。当前文章为起步内容，本站攻略是通用建议，不包含未经验证的数值。
