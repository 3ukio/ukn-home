## 今回の変更点

**4クラス調整、スティグマ5個装着、ワールド取引所・ワールド交換所追加**。対象の超越週間ミッションは調律石が**週最大12個**に増えます。

## クラス調整

| クラス・スキル | 変更 |
|---|---|
| テンプラー・審判 | PvPダメージ約**5%減**。特化2の衝撃系状態対象への追加PvPダメージ約**10%減**、特化3の命中時追加PvPダメージ約**10%減**。 |
| レンジャー・標的の矢 | 特化1の持続中の完璧増加 **5% → 10%**。 |
| レンジャー・祝福のボウ | 再使用 **2分 → 1分30秒**。 |
| チャンター・百裂撃／破裂撃 | 特化5の多段ヒットは維持。ブロック・回避無視を削除。 |
| チャンター・回転撃 | 特化5のクリティカルヒットは維持。ブロック・回避無視を削除。 |
| スピリットマスター・冷気衝撃／真空爆発／大地の震動 | 特化4の「大地の震動」命中時の攻撃力増加 **2% → 10%**、最大重複 **5回 → 1回**。バフ解除スキルの影響を受けなくなります。 |
| スピリットマスター・元素結集 | クリティカルダメージ増加はレベル1で **1.1% → 5.5%**、レベルごと **0.1% → 0.5%**。重複不可に変更。 |

## ワールド取引とマイナスギーナ

ワールド取引所・ワールド交換所は、ともに**取引税率20%**。

不正取引対象のアカウントにマイナスギーナを設定。残高がマイナスの間は、取引所の購入・販売登録・精算、交換所の販売登録・精算、サーバー移動を制限します。討伐、オードエネルギーキューブ、ギーナ箱などで**刻印されていないギーナ**を得て残高を戻し、**0以上**になると解除されます。

## スティグマ・週間報酬

- スティグマ スキルは**最大5個**。新しい入手経路で得られるスティグマ シャード（刻印）は合計**50個**。全員への直接配布ではありません。
- 悪夢商店・シューゴフェスタ商店：各キャラクターの購入上限 **35 → 50個**。
- そよ風商会の「特殊」：**1個250,000ギーナ、キャラクターごと20個**。
- 超越週間シーズンミッション「**超越した者たちの**」Step 1～3：各**調律石（唯一）（刻印）4個**、週最大 **3 → 12個**。

## デイリーダンジョン・アビス回廊

**クロバキンの秘密の保管所**を追加。クリアスコアに応じてギーナ（刻印）を獲得し、**ディーヴァ生体研究基地・オディウム貯蔵所と入場回数を共有**します。

アーティファクト占領戦ですべてを相手種族に奪われると、劣勢陣営の拠点にアビス回廊ポータルが出現。この条件で入ると、**AP獲得量が30%減少**します。
