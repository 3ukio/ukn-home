# 第三轮视觉与排版说明

本轮在原 redesign-v2 分支优化，没有更换架构，没有推送 GitHub、合并 main 或部署 Cloudflare。

## 视觉与信息组织

- 品牌统一为 AION2 NOW，辅助名称在 src/config/site.ts 的 subtitles 中集中配置。日文「ナウ」、英文「NEWS & UPDATES」、繁中「國際服更新資訊」。仍使用本站原创简洁标记。
- 默认深色，保留用户已存的浅色或深色偏好。现有用户曾选择浅色时仍显示浅色，这是尊重已保存的选择；新访客默认深色。
- 新样式集中于 src/styles/notices.css。旧 v2.css 保留在项目中，但不再加载。
- 主要字号：标题约 28–32px、正文 17–18px、导航和列表 16–17px、日期及来源 14px；字重分为 500、600、700。
- 首页是约 112px 的原创 CSS 蓝黑横幅，随后立即是公告分类和公告列表。没有大型宣传口号或强制配图。
- 公告列表包含分类、标题、真实发布日期、官方参考链接和适用版本。标题和外部来源是独立链接，不嵌套链接。
- 无已核实的国际服公告时保持空状态。原创编辑指南与官方公告分开显示，没有编造更新或处罚数字。
- 详情页前置发布日期、地区、官方来源、更新时间及核实日期。CSS 横幅之后保留自由 Markdown 章节，不强制套用固定更新章节。
- 列表按真实发布时间排序；官方资讯使用官方发布时间，本站指南使用本站首次发布时间。排版编辑的 updatedAt 不会把旧公告顶到最新。日文列表日期显示「10月28日（水）」，title 属性及详情保留完整年份；星期来自真实日期计算。

## 用 Markdown 添加重点

以后只改文章，不需要每次修改 CSS。

普通段落直接写文字。行内重点用一对双星号：

```md
普通说明中包含 **需要强调的内容**，其余保持正常字重。
```

整段重要内容建议单独成段，前后留空行：

```md
普通段落介绍背景。

**重要：预计结束时间不代表官方确认维护结束。**

继续解释具体内容。
```

中文、日文如果把句号、括号等标点放在双星号内部，外侧又直接接另一个句子，标准 Markdown 有时无法识别。重要句单独成段最稳妥，也更易阅读。不要把双星号写成全角符号。

二级小标题：

```md
## 本次更新重点
```

项目列表：

```md
- 第一条经过核实的说明。
- 第二条说明，可包含 **重点**。
```

可选的简洁提示框使用标准引用语法，不需要额外组件或依赖：

```md
> **提示：** 请核对公告适用地区与原文时区。
```

官方来源链接：

```md
[官方公告](https://aion2.plaync.com/en-us/board/notice/list)
```

以上仅为写作格式示例，不是新的游戏公告。当前三语言官方来源阅读指南、日文维护阅读指南已对原有关键句加粗，未改变游戏事实或首次发布日期。格式编辑的更新时间记录了实际编辑时间。

## 保留功能与限制

保留三语言、对应文章语言切换、缺译回退、主题保存、Content Collections 校验、维护时区转换、SEO、canonical、hreflang、sitemap、robots 和 404。小剑星接口仍关闭，没有加载角色图或动画代码。

未新增依赖、自动抓取、搜索、角色动画、数据库或其他运行服务。联系方式仍待站主提供；当前没有已核实的版本、维护、处罚公告。此前旧依赖的审计事项未在本轮跨版本升级。

## 预览与构建

在项目根目录执行 npm run build；node scripts/verify.mjs 运行现有及本轮回归检查。预览命令为 npm run preview -- --port 4322。

根路径 / 是语言入口；三语言路径保持 /ja/、/en/、/zh-tw/。本轮没有改变正式域名、部署配置或现有文章 URL。
