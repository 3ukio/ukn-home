## 挑戦前に決めること

**ラフの爆弾を受け渡す相手、ケトゥの落下球を取る2人、ルドラの赤い球を取る防御役を決めておく。** 最終ボスの赤・青の待機位置も共有する。

**グローバル版ギミックは実戦確認待ち。** 以下は調整前のノーマル戦を想定した予習用の動き。グローバル版の発動HP、正確な秒数、ハード固有の変更は未確認。

| 項目 | 内容 |
|---|---|
| ダンジョン | 深淵の再錬：ルドラ |
| 難易度・入場アイテムレベル | **ノーマル：2,800／ハード：3,000** |
| 人数 | **10人、5人パーティー×2**。プレイヤー攻略の編成 |
| 公式の制限時間 | 両難易度とも**2時間** |
| 主な報酬 | 帰属のルドラ武器・盾、ブレスレット、翼、絵画 |

アイテムレベルは**入場条件**であり、初クリアを保証する装備水準ではない。ノーマルとハードは報酬の種類が共通で、ドロップ率が異なる。

## 進行と担当

1. **中央の深淵融合炉：** 中央を攻撃しつつ、補助融合炉が出たら担当者が上昇気流で向かって破壊する。残すと中央を壊しにくくなる。
2. 道が開いたら、**第1パーティーは離隔のラフ、第2パーティーは深淵の翼ケトゥ**へ。
3. 最後は**永劫のルドラ**で合流。赤い球の担当と色分けを再確認してから開始する。

この分担はプレイヤー攻略の進行例。グローバル版の経路や追加条件は実戦確認待ち。

## ラフ：ブラックホールを増やさない

| 合図 | 動き | 失敗すると |
|---|---|---|
| レーザーと狭い安全地帯 | 安全地帯の横で待つ。赤い範囲の対象者は味方の逃げ場を塞がず、範囲が固定されてから入る。 | レーザー接触で倒される。誘導を誤ると逃げ道を塞ぐ。 |
| 紫の爆弾タイマー | **輪が満ちる前に受け渡し相手へ近づく。** 消えるまで交代で受け渡す。 | 1人で期限を迎えるとブラックホールが残る。 |
| 全員に赤い円 | 集まって円を重ねる。外へ飛ばされたら再集合し、その後の持続床は外周に寄せる。 | 散開すると円の重なりから外れる。床を中央に置くと戦闘場所が狭くなる。 |
| フィールドが4分割 | 追加の床を外側へ寄せ、移動できる通路を残す。 | 床で進路を潰すと回避が難しくなる。 |
| 捕食者4体と対象指定 | 対象者がラフのレーザーを捕食者に通す位置へ移動する。 | 撃ち漏らすとブラックホールが増える。旧仕様は**3個で全滅**。 |

**爆弾は期限前に声をかける。** 次の担当者がアイコンに気づくまで待たない。

## ケトゥ：落下球と保護を担当制に

| 合図 | 動き | 失敗すると |
|---|---|---|
| かくれんぼのレーザー | ミニマップ6時側で最初のレーザーを避け、霊を倒しながら12時側へ進む。白い範囲が閉じたら中央の紋章に集合し、回復を合わせる。 | 閉じる範囲に取り残されたり、集合が遅れたりすると攻撃にさらされる。 |
| 目のマーク・飛びかかり・武器の引き抜き | 着地を避け、武器を引き抜く際の**地面の輪をジャンプ**する。 | 飛びかかりだけを見ると追撃の輪に当たる。 |
| 落下する球2個 | **タンク以外の担当2人が1個ずつ**、着地前に受け止める。 | 取り逃すと処理失敗。グローバル版の具体的な罰則は実戦確認待ち。 |
| 赤・青の球による向き判定 | **赤には正面、青には背中を向ける。** | 向きが逆だと判定に失敗する。 |
| 扇形攻撃とソウルストーン | 集合して扇形を重ね、向きが固定されたら離れる。続く回避不能攻撃の直前に石を壊し、短時間の保護を使う。ヒーラー用も残す。 | 早く壊しすぎると着弾時に保護が残らない。 |

旧攻略の固定カウントはグローバル版では未確認。実際の範囲固定と詠唱を見て動く。

## 永劫のルドラ：安全マスを即コール

| 合図 | 動き | 失敗すると |
|---|---|---|
| 足踏みと紫の衝撃波 | **来る輪を1本ずつジャンプ。** 近接は頭の動きに巻き込まれない距離を取る。 | 1回で止まると次の輪に当たることがある。 |
| 青い球と赤い球 | 青を分担して回収。赤は担当者が**対応する防御スキルを先に使ってから**取る。 | 防御なしで赤を取ると爆発。グローバル版で有効なスキルは実戦確認待ち。 |
| 各自への床攻撃 | 床を重ねすぎず、移動経路を残して散開する。 | 重ねると被害が増え、移動先もなくなる。 |
| 格子状の床 | 対象の床攻撃を当ててマスを探す。遠距離は外側、近接は内側を担当。**青い柱が出た安全マスを即コールし、全員で入る。** | 発見や集合が遅れると保護を受けられない。 |
| 赤・青のマーク | 決めておいた色別の側へ移動し、異色の人と離れる。 | 異色同士が近づくと互いにダメージを受ける。 |
| 最後のブレスと色付きの円 | **自分と同色の円へ、保護がブレス中に切れないタイミングで入る。** | 早く入りすぎると攻撃終了前に保護が切れる。 |

**「こちら側なら1回／2回」と固定で覚えない。** 提供資料は第2段階の左右と跳ぶ回数が一致していない。グローバル版の跳ぶ回数、格子の発動HP、ブレスの秒数、ボスの狂暴化時間は実戦確認待ち。公式の**ダンジョン制限2時間**とは別の話。

## 全滅を減らす5つの声かけ

- **ラフ「爆弾交代」：** 期限前に受け渡し、ブラックホールを増やさない。
- **ケトゥ「左の球／右の球」：** 担当2人が開始前に返事をする。
- **ケトゥ「石を残す」：** 回避不能攻撃用の保護とヒーラー用を確保する。
- **ルドラ「安全マスここ」：** 複数の曖昧な方向指示より、1人が場所を明確に伝える。
- **ルドラ「赤の防御OK／同色へ」：** 防御の再使用待ちを確認し、ブレスでは早入りしない。

## 初回の動き方

各パーティーに進行役を置き、ミニマップの向きと集合マーカーを統一する。爆弾、落下球、赤い球には交代要員も決める。担当用の防御スキルを通常攻撃への対処で使い切らない。

初回は新しい合図を声に出し、旧パターンと同じか確認する。**このノーマル戦の予習だけでハードの全ギミックを処理できるとは考えない。**

## 報酬と交換

グローバル版で確認されているのは、**ルドラの武器・盾（帰属）**、**ルドラのブレスレット（帰属）**、**深淵のブレスレット（帰属）**、**Sealed Abyssal Waves Wings**、**Artwork: Abyssal Ludra**。ノーマルとハードで報酬の種類は同じだが、確率は異なる。

- 深淵のブレスレットは突破**3**、ルドラのブレスレットは**5**まで。
- 両難易度の確定報酬で、それぞれに対応する帰属の**Gear Change Voucher**を選択できる。
- **ノーマル券6枚 → ルドラのブレスレット（帰属）1個**。または**ハード券3枚 → 1個**。
- 物質変換で**ノーマル券2枚 → ハード券1枚**。
- Gear Change Voucherは**Abyssal Forge: Weapon Selection Chest (Bound)**への物質変換にも使用可能。必要枚数はパッチに記載されていない。

他の変更点は[11月4日グローバル版アップデート](/ja/articles/global-update-2026-11-04/)へ。
